# Config Catalog

Use this skill when changing `catalog/` entries for skills, agents, MCP servers,
providers, model profiles, or harness settings.

Keep source data portable. Harness-specific details belong in adapters or
`catalog/harnesses/`, not in skill bodies or agent prompts.

For deeper guidance, see `references/catalog-rules.md`.
